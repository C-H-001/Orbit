Orbit 是一个在本地运行的求职管理工具。它会读取招聘邮件、识别邮件意图、更新申请状态，并把每一次变化和原邮件关联起来。除了申请追踪，Orbit 也提供面经采集、随机抽题和基于个人求职数据的智能对话。

## ✨ 功能一览

- 📬 **邮件自动整理**：通过只读 IMAP 同步招聘邮件，识别投递、笔试、AI Coding、面试、录用和拒绝等事件。
- 🧭 **申请进度追踪**：自动创建或更新申请记录，集中查看公司、岗位、招聘进度、关键时间和最后更新时间。
- 🔗 **原邮件随时回看**：每条进展都可以回到对应邮件，查看原始 HTML、图片和附件信息。
- ⚠️ **长期未更新提醒**：超过七天没有新进展的记录会显示提醒，也可以单独筛选出来。
- 💬 **智能对话**：直接询问自己的求职进度；涉及数据修改时，会先展示确认卡。
- 📚 **面经收集**：使用 Chrome 插件采集牛客网和小红书面经，确认后保存到面经库。
- 🎲 **随机抽题**：从已经收藏的面经中随机抽取三个问题，随时进行面试练习。
- 🗂️ **本地数据管理**：支持手动编辑、删除、恢复、CSV 导出和公司招聘官网备忘录。

## 📬 邮件如何变成申请进度

Orbit 使用只读 IMAP 获取邮件，不会修改邮箱中的内容，也不会代替用户发送邮件。

同步完成后，模型会判断邮件属于哪一类招聘事件，并提取公司、岗位、时间和下一步信息。相关邮件会被合并到同一条申请记录中；每次更新都会保留来源，因此可以从进展时间线直接查看原邮件。

不同类型的流程会分别记录：

- **职位申请**：需要识别到明确岗位，才会创建或匹配职位记录。
- **笔试**：必须识别公司，但岗位可以为空；同时区分具体考试时间和截止时间。
- **AI Coding**：作为独立流程保存，不与普通笔试混在一起。

重复同步同一封邮件不会重复创建邮件、申请或时间线记录。

## 📊 概览：集中管理所有进度

概览展示当前仍在跟进的申请、笔试和 AI Coding。每条记录只显示当前招聘进度，并提供最后更新时间、完成状态和详情入口。

在详情中可以：

- 查看完整进展时间线；
- 跳转到每个进展对应的原邮件；
- 编辑公司、岗位、日期和时间；
- 将事项标记为已完成；
- 删除或恢复申请记录。

页面下方的“公司官网备忘录”可以手动保存公司招聘网址，方便回到官网确认不会通过邮件通知的状态变化。

## ✉️ 邮箱：查看 Orbit 已同步的邮件

邮箱页面保存的是本地邮件副本。它支持分页、搜索、隐藏已忽略邮件、单封删除和批量删除。

打开邮件后，Orbit 会优先展示原始 HTML 内容，并处理内嵌图片和附件信息。删除本地邮件不会删除真实邮箱中的邮件。

## 💬 智能对话：询问自己的求职数据

智能对话会根据当前申请和邮件数据回答问题，例如：

- 我最近有哪些面试？
- 哪些申请已经很久没有更新？
- 这周有什么笔试或截止时间？

普通查询不会修改数据。如果对话涉及修改申请，Orbit 会先生成确认卡，只有用户确认后才会写入数据库。对话内容只保留在当前网页会话中，关闭网页后会清空。

## 📚 面经收集：从网页保存到面经库

Orbit 的 Chrome 插件会读取当前页面中用户能够看到的内容：

- **牛客网**：提取帖子正文中的公司、岗位、面试轮次、问题和答案。
- **小红书**：获取当前笔记的轮播图片，并使用视觉模型识别其中的问题和答案。

采集结果会先显示在插件侧边栏中。确认内容后再保存到 Orbit；保存完成后可以继续采集下一篇面经。

Orbit 不会绕过登录、订阅或网站访问限制，只处理当前用户可以正常查看的内容。

## 🔒 数据保存在本机

Orbit 默认把所有运行数据保存在项目的 `data/` 目录：

```text
data/
├── config.json          # 邮箱和模型配置
├── orbit.sqlite         # 申请、邮件、面经和用量数据
└── interview-captures/  # 面经采集图片
```

该目录不会被 Git 提交。`config.json` 中包含明文邮箱凭据和 API Key，请不要分享或公开这个目录。

邮件和网页内容会发送给用户自行配置的模型服务商进行识别。使用前请确认对应服务商的隐私政策符合自己的要求。

## 🧩 安装 Chrome 面经采集插件

先构建插件：

```bash
pnpm build:extension
```

然后：

1. 打开 `chrome://extensions/`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择项目中的 `dist-extension` 文件夹。

插件固定连接 `http://127.0.0.1:8787`，使用时需要保持 Orbit API 正在运行。

## 🛠️ 构建与检查

```bash
pnpm typecheck  # TypeScript 类型检查
pnpm test       # 运行测试
pnpm build      # 构建 Web 和 Chrome 插件
pnpm start      # 启动构建后的应用
```

生产构建启动后，可以通过 <http://127.0.0.1:8787> 访问 Orbit。

## 📁 项目目录

```text
src/        Web 前端
server/     API、邮件同步、Agent 和 SQLite 数据层
shared/     Web、服务端和插件共用类型
extension/  Chrome 面经采集插件
scripts/    构建检查脚本
```

Orbit 当前面向单用户本机使用，不包含账号登录、多用户权限、云端部署、发信或邮箱写回功能。
